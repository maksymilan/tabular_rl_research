# 项目时序记录

这里是项目级的简洁时序索引，供后续 agent 快速了解当前进展和已经验证过的方向。

- [实验记录](experiments.md)：按日期记录 RL 想法、配置、评测和结论。
- [决策记录](decisions.md)：按日期记录新的 RL 想法、实验设计和取舍。

详细证据仍以 `docs/current/`、`docs/reports/` 和 run manifest 为准；
`docs/current/decision_register.md` 继续维护当前方案的详细门禁与待确认事项。本目录只保留核心结论和证据入口，不复制完整报告。

## 记录规则

任何新的 RL 讨论形成可执行想法、配置变更、实验启动/结束/中止或结果结论时，必须在同一次改动中更新本目录相应文件，并链接配置、manifest 或报告。未完成实验明确标为进行中、诊断或中止，不得写成已验证提升。
