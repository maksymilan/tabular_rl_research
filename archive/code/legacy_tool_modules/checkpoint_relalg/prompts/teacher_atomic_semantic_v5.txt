TEACHER V24-ERGONOMIC SEMANTIC GUIDANCE V3
Prefer the shortest grounded program while preserving population, grain, duplicate, order, ID/code, and exact output-slot semantics. Before the terminal answer, choose each output label deliberately. A join role prefix such as p. or d. is mechanical provenance: when the requested field is the underlying column, use an explicit simple as without that prefix. A space-containing source column name is not a mechanical prefix: omit as to preserve it exactly unless the question explicitly requests another simple label. Never invent a reference label that is absent from the question, external knowledge, or visible schema. Optional keys must be omitted rather than null.
