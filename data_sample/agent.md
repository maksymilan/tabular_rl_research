# Data Sample Agent Notes

This directory stores small JSON samples extracted from full datasets for inspection and tool-use case construction.

Sample file schema:
- `dataset`: local dataset key.
- `description`: short dataset/subset purpose.
- `source`: Hugging Face repo, local input path, source format, and split/subset.
- `selection`: sampling mode, seed when applicable, requested count, and actual count.
- `records`: sampled dataset rows.

Samples are generated by:

```bash
python3 src/data_pipeline/extract_samples.py --dataset all --num 5
```

For case design, inspect `records[*].table`, `records[*].question`, and `records[*].answer`. For `tqabench`, `records[*].table` is a compact parsed view for observation; return to the raw parquet in `data/tqabench/` when a complete table is needed.
