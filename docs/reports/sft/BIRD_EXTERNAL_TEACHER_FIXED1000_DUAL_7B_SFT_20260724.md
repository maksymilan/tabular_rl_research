## Fixed-1K task cohort

pool. The additional cohort is therefore the exact, disjoint 800-task complement rather than a new
random sample.

## External teacher

The additional 800 tasks were generated by a real DeepSeek V4 Flash model-harness loop. Each turn
saw only the legal episode prefix represented by current state and rolling legal history; gold SQL
was hidden from the model. Configuration:

- protocol `version10`;
- temperature 0, thinking enabled, `reasoning_effort=high`, JSON output constraint;
- four legal history turns, full resident-state prompt, optional plan;
- at most 30 semantic actions and one causal attempt per task;
- `bird-set` terminal denotation.

The primary pass produced 540/800 successes. A provider-carrier audit found 26
infrastructure-incomplete tasks: empty visible content or API exhaustion rather than meaningful
semantic actions. Empty carrier responses are now retried at the client boundary and do not spend
the semantic action budget. Causal provider-only reruns recovered 19 tasks; seven reruns became
ordinary wrong answers.

Final additional-800 accounting:

| Outcome | Count |
| --- | ---: |
| Correct | 559 |
| Wrong answer | 236 |
| Argument-validation failure | 3 |
| Execution failure | 2 |
| Unresolved transport/provider failure | 0 |

Thus the additional cohort succeeds on 559/800 (69.875%). Combined with the frozen core's 145/200,
the fixed-1K teacher success is **704/1,000 (70.4%) under `bird-set`**.

## Replay and SFT admission

All 704 successful trajectories passed fresh execution replay and structural/no-leak checks:
704/704. They yielded 4,782 legal action targets before token filtering.

Admission uses the exact installed LLaMA-Factory `qwen` template with `mask_history=true` and
`cutoff_len=6400`. A record is kept only when:

1. its final assistant target is complete;
2. its current task/state source is complete;
3. its oldest rolling history pair is complete when history exists.

There is no reasoning word limit. No reasoning, action, state, or history is rewritten. Rejected
records are omitted individually; valid earlier actions from the same causal episode remain valid.

| Token-gate result | Count |
| --- | ---: |
| Input records | 4,782 |

| Omitted records | 663 |
| Final-target truncations | 0 |
| Incomplete current source | 4 |
| Incomplete oldest history pair | 662 |
| Contributing episodes | 704 |
| Episodes with at least one omitted record | 162 |
| Fully retained episodes | 542 |

Three records satisfy both omission reasons. Both base-model tokenizers retain the exact same
records; their final JSONL outputs are byte-identical.

## Training configuration

The comparison changes only the base checkpoint and output path. Both runs use:

- 4-bit QLoRA, rank 16, alpha 32, dropout 0.05, all linear targets;
- 40,370,176 trainable parameters (0.5273%);
- batch size 1, gradient accumulation 16, effective batch 16;
- two epochs, 258 optimizer steps per epoch, 516 total;
- learning rate `1e-4`, cosine scheduler, warmup ratio 0.03;
- bf16, paged AdamW 8-bit, gradient checkpointing;
- seed and data seed 42;
- identical dataset order, template, masking, and cutoff.

- `src/sft/configs/bird_external_teacher_qwen25_7b_qlora_6400.yaml`;
- `src/sft/configs/bird_external_teacher_qwen25_coder_7b_qlora_6400.yaml`;
