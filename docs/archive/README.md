# Archive

This directory preserves superseded designs, plans, reports, and project history for audit. Nothing
under this directory is a source of truth for new data generation, training, or evaluation.

- `gold_sql_compiler/`: documentation for the retired SQL-compiled trajectory pipeline.
- `trajectory_enrichment/`: handoff material for the retired complete-trajectory enrichment path.
- `legacy_tool_design/`: early memory/context tools and hand-authored example trajectories.
- `plans/`: superseded experiment and data-generation plans.
- `migrations/`: completed infrastructure migration notes.
- `project_log.md`: the pre-cleanup full chronological `AGENTS.md` memory.
