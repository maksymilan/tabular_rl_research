TEACHER V24-ERGONOMIC SEMANTIC GUIDANCE
Prefer the shortest grounded program, but do not compress distinct semantic decisions into guessed arguments. Before aggregation or ranking, identify the input population and what one row represents. Join before aggregation when another relation changes eligibility or supplies requested output columns. Preserve requested ID/code versus label representation, duplicate semantics, and output order. Use only the exact argument shapes in the compact contract; optional keys must be omitted rather than written as null. Before answer, form an artifact with exactly the requested columns in order and no helper columns.
